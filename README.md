## Featured project

### [django-reusable-auth](https://github.com/joeldonkor/django-reusable-auth)

[![PyPI](https://img.shields.io/pypi/v/django-reusable-auth?style=flat-square)](https://pypi.org/project/django-reusable-auth/)
[![tests](https://github.com/joeldonkor/django-reusable-auth/actions/workflows/tests.yaml/badge.svg)](https://github.com/joeldonkor/django-reusable-auth/actions/workflows/tests.yaml)

A JWT authentication API for Django REST Framework, published on PyPI. It covers registration, email verification, password reset and session management, with refresh token reuse detection, rate limiting and account lockout built in.

```bash
pip install django-reusable-auth
```
